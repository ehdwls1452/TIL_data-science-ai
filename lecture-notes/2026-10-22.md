## 아핀변환
화면 속 점 3,2를 가로 세로가 n배 늘어났고, 옮긴다고 가정하에 아핀변환 사용할 수 있다.
## 뉴런
뉴런은 입력을 받아 출력 하나를 만드는 계산 단위
## 레이어와 신경망
레이어는 여러 뉴런을 모아 놓은 계산 단계
신경망은 이런 계산들을 연결한 모델
학생 기록 - 중간숫자 - 최종점수 <- 이 각 단계가 레이어에 해당 
## 활성화 함수
활성화 함수는 뉴런의 가중합에 편향을 더한 값을 다시 바꾸는 규칙
이미 계산된 식에 임의의 식을 더해서 그 기록과 규칙을 바꾸려고 하는 것
## 비선형 함수
선형 변환이 지켜야 하는 덧셈 및 배수 관계를 모두 만족하지 않는 함수
## 은닉층
입력과 최종 출력 사이에서 중간 값을 만드는 계산 단계
은닉이라는 단어가 들어가 있지만, print()로 중간값 확인 가능
출력층(최종 산출)은 이 [3,0]을 조합하여 최종 점수를 만든다
실제 신경만 계산에서는 입력을 여러 중간 값으로 바꾸어 계산을 진행한다
## 출력층
모델의 최종 결과를 만드는 계산 단계
## 순전파
입력부터 최종 출력까지 계산을 앞 방향으로 진행하는 과정
1. 가중합과 편향을 계산
2. 렐루를 적용하여 H = [3,0]을 만들고
3. 출력층에서 3X2 + 0X(-1) + 1 = 7 을 산출한다
1-2-3 이 과정을 순전파라고 부른다

# 2.1 분류 점수와 Logit
분류 점수는 확률로 바꾸기 전에 모델이 계산한 숫자
모델이 중간 점수 0.8을 냈다고 가정해보면, 이 숫자 자체는 80%가 아니라 그냥 그 점수 값을 의미
이 숫자가 sigmoid라는 함수를 만나 0.69라는 확률로 계산될 수 있다
## Sigmoid 시그모이드
시그모이드는 점수 하나를 0과 1 사이로 바꾸는 함수
## Softmax 소프트맥스
한 대상의 여러 클래스 점수를 합이 1 인 클래스별 확률로 바꾸는 함수
문의 종류마다 각 클래스의 확률값을 모두 볼 수 있다
## Argmax 아그맥스
가장 큰 값이 있는 위치 번호를 찾는 연산
확률과 이름을 한번에 같이 표현할 때 쓴다
## 조건부 확률
특정 조건을 만족하는 경우만 모아서 보는 확률
## 베르누이 분포
결과 두가지일때 한번의 결과를 0/1로 나타내는 확률 모형
## Liklihood (우도)
이미 관측한 데이터를 고정해 놓고, 파라미터에 따라 그 데이터에 부여되는 확률을 비교하는 함수

- 확률은 모델을 정해두고 가능한 결과 살펴보는 방법
- 우도는 실제 출력된 결과를 보고 모델의 파라미터 값을 보는것
## 파라미터 후보와 후보 비교
파라미터 후보 = 시험해볼 파라미터 값
각 후보에 같은 데이터를 넣어 우도를 구한 다음에 가장 큰 우도를 주는 후보를 선택

## 최대우도추정과 MLE
관측데이터의 우도가 가장 커지는 파라미터를 찾는 방법
공통 p를 사용하는 독립 베르누이 모형에서는 MLE = 구매수 / 전체 고객 수

## 인덱스와 Argmax
인덱스는 배열의 위치 번호, np.argmax()는 가장 큰 값 자체가 아닌, 그 값이 들어있는 위치 번호를 반환
가장 좋은 평가값을 빠르게 찾고 그 뒤 값을 만든 설정까지 빠르게 찾기 위함
## 로그 우도 (Log Likelihood)
우도에 자연로그 적용한 값
각 관측 확률의 자연로그를 더해서도 같은 값을 얻음
같은 데이터에서는 큰 로그우도를 선호
## 같은 데이터에서의 모델 비교
같은 고객의 같은 실제 결과에 대해 각 모델이 부여한 우도를 비교한다
한 고객에게서 더 좋은 확률은 준 모델이 다른 고객 또는 전체 데이터에서 항상 좋은 것은 아니다
## 손실 함수와 Loss
모델의 예측을 실제 정답과 비교하여 숫자로 평가하는 규칙
금액 예측은 실제값과 예측값의 차이로 MSE를 구할 수 있다
구매 여부와 상품 종류는 실제 정답에 주어진 확률로 BCE 또는 CE를 구할 수 있다
문제 종류에 맞게 계산 규칙을 선택한다
손실함수는 모델의 예측을 비교하고 학습 중 어떤 것을 줄여야하는지 정하는 역할을 한다
## 제곱오차합과 SSE
제곱오차를 모두 더한 값
SSE를 통해 MSE를 구할 수 있고, 합계가 커진 이유 자체가 오차인지, 데이터의 수의 영향을 받았는 지 구분할 수 있다
## 평균제곱오차 MSE
제곱오차의 평균
각 고객의 오차를 제곱하고 모두 더한 뒤 전체 고객 수로 나눈다
여러 수치의 예측 제곱오차를 하나의 평균으로 요약해 비교하기 위함
오차를 전체 수로 평균을 내기 때문에 각 한건에 대한 오차범위를 대략적으로 파악 가능
오차를 제곱하면 단위도 제곱
단위가 만원단위였으면 제곱오차에 대한 해석도 (만원)^2 단위로 읽으면 된다
## 이진 교차엔트로피와 BCE
Binary Cross Entropy :  구매 / 미구매 구분하는 분류 손실함수
한 고객의 BCE 는 실제 정답 확률에 음의 로그 적용한 값
두 예측 결과를 학습하고 평가할 기준으로 쓴다
각 정답에 어느 정도의 확률을 부여했는지는 알 수 없다
## 범주형 교차엔트로피와 CE
Categorial Cross Entropy : 여러 종류 중 실제 정답이 하나인 분류에 쓰이는 손실
과일 선택처럼 대상마다 열의 확률을 고르고 대상별 손실을 평균 내는 계산을 활용할 수 있다
