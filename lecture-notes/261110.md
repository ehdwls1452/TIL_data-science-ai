# 텍스트 임베딩과 의미 유사도
숫자 칼럼 기준으로는 처리 과정이 정해져 있는 편이지만
텍스트 분석은 원본 자체를 바꾸는 경우가 많이 있다

## 헷갈렸던 것

>임베딩은 단순히 텍스트를 벡터화 하는건가? 아니면 벡터화된 텍스트를 특정 함수에 넣어서 뽑아낸 값인가?

문장 임베딩 : 텍스트를 일단 숫자 (백터) 로 만들고, 그걸 학습된 함수에 넣어서 뽑아낸 결과

>코사인 유사도는 문장이 '겉보기에 얼마나 유사한지'를 암시하나?

그보다는 같은 주제, 맥락에 있는 정도 (주제적 관련성) 에 가깝다
그래서 임베딩은 **같은 주제 찾기**에는 강하지만 **사실관계 판단**에는 약하다
